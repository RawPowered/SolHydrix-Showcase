# Preliminary credit application example

[Download the blank fillable SolHydrix PDF](SolHydrix-Basic-Credit-Application.pdf).

This one-page AcroForm demonstrates a branded downloadable document. It requests basic applicant and optional co-signer details, including income type and amount. It has no Social Security number field, bank account field, embedded submission action, credit pull authorization, or PDF JavaScript.

The visitor fills and saves the PDF on their own device. The website does not collect the completed file. A lender has not been selected, so the document is a preliminary intake example. The lender's required application, notices, transfer method, and approval process must be reviewed before real financing use.
